BusLive 모형 노선정보 앱

1. ZIP을 모두 풉니다. PC에 Python 3가 설치된 상태에서 start.bat을 실행합니다.
2. PC 브라우저에서 http://127.0.0.1:8765 를 엽니다.
3. 휴대폰은 PC와 같은 Wi-Fi에 연결하고 서버 창의 LAN 주소를 엽니다.
   연결이 막히면 PC의 개인 네트워크 방화벽 설정과 공유기의 기기 간 통신 설정을 확인합니다.
4. 51 / 6719 / 220 / G1124 중 하나를 선택합니다.
   운행 미리보기 버튼을 누르면 5초 간격으로 5개 정류장을 왕복합니다.
   두 방면 버튼으로 정류장 순서를 각각 볼 수 있습니다.
   가상 교통은 정류장 사이를 원활·서행·정체로 표시하며 1분마다 바뀝니다.
   왕복 양쪽 화면에서는 같은 구간에 같은 상태가 표시됩니다.
   시간대별 가상 혼잡도는 노선·방면별 모의 패턴이며 테두리가 있는 막대는 현재 시간입니다.
   노선의 버스 아이콘은 정류장 통과 직후 확인 위치를, 이후 점선으로 구간 내 추정 위치를 표시합니다.
   예상 도착은 선택한 방면의 앞쪽 정류장에 표시합니다. 기본 구간 시간은 25초이며
   연속 정류장의 통과 기록을 받으면 노선별 평균을 갱신합니다.
   다음 예상 시각까지 센서 통과가 없으면 도착 표시가 '통과 확인 대기'로 바뀝니다.
   미리보기는 화면에서 확인하기 쉽도록 실제 앱의 모의 운행 속도인 5초 간격으로 표시합니다.
   지도를 열어도 정류장 목록과 구간 교통 색상은 계속 보입니다.
   목록과 지도는 같은 버스 위치를 표시하고, 대기 중에는 버스 아이콘 옆에 '회차 대기'가 붙습니다.
   미리보기 중에 '회차 대기'를 누르면 다섯 번째 정류장에 도착해 멈추고, '복귀 출발'을 누르면 복귀를 시작합니다.
   ESP32 운행 화면에서는 회차지가 마지막 통과 위치일 때 대기를 표시할 수 있습니다.
   이 버튼은 브라우저의 표시 상태를 바꾸며, ESP32가 다음 정류장을 보내면 자동으로 대기가 해제됩니다.

ESP32-S3 연결

1. Arduino IDE의 보드 매니저 URL에 아래 주소를 추가합니다.
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
2. 보드 매니저에서 esp32 by Espressif Systems를 설치합니다.
   model_bus/model_bus.ino를 열고 보드에 맞는 항목(일반 보드는 ESP32S3 Dev Module)과 COM 포트를 선택합니다.
   별도 Arduino 라이브러리는 필요 없습니다.
3. WIFI_NAME과 WIFI_PASSWORD에 2.4GHz Wi-Fi 정보를 넣습니다.
   SERVER_URL에는 서버 창의 LAN 주소 뒤에 /api/share를 붙입니다.
   MODEL_KEY에는 서버 창에 표시되는 키를 넣습니다. 이 키는 앱 폴더의 .model-key에 저장됩니다.
   ROUTE는 모형에 붙인 번호(51, 6719, 220, G1124)로 바꾸고 각 모형에 업로드합니다.
   현재는 노선당 모형 1대 기준입니다.
4. 보드에 푸시버튼을 달면 한쪽을 GPIO4, 다른 쪽을 GND에 연결합니다.
   HW-870을 쓴다면 보드 안에서 바닥 방향으로 설치하고 VCC→3V3, GND→GND, DO→GPIO4로 연결합니다.
   HW-870 위에 표시가 없을 때 LOW라면 코드의 ACTIVE를 HIGH로 바꿉니다.
   스티커로 감지시키려면 먼저 흰 종이와 실제 간격을 사용해 HW-870의 감도 나사를 조정합니다.
   고정 표식을 하나 지나갈 때 한 번씩 감지돼야 합니다. 짧은 신호는 전송 중 누락될 수 있으므로 첫 시험은 표식에서 잠깐 멈춥니다.
5. 모형을 네 노선 중 해당 출발지에 두고 재시작합니다. 출발지는 재시작하면 자동으로 등록됩니다.
   이후 정류장마다 버튼을 한번 누르거나 표식을 한 개 감지하게 합니다.
   첫 정류장 → 2 → 3 → 4 → 5(회차) → 4 → 3 → 2 → 첫 정류장 순서입니다.
   센서는 정류장 이름을 읽지 않으므로 감지를 놓쳤다면 모형을 출발지에 두고 재시작합니다.
   TIMED_DEMO를 true로 바꾸면 보드가 5초마다 모의 위치를 보냅니다.
6. 화면에서 미리보기를 끈 상태로 실제 입력을 확인합니다. 보드 시리얼 모니터는 115200이며 HTTP=200이면 전송 성공입니다.
   마지막 수신 후 12초가 지나면 화면에서 모형의 위치가 사라집니다.

노선과 접속판

51번과 220번은 각각 부산, 김해 노선의 기점 쪽 5개 정류장을 사용합니다.
6719번에는 부산의 실제 정류장 5곳, G1124번에는 김해의 실제 정류장 5곳을 임시 배정했습니다.
모형 회차지는 다섯 번째 정류장이며, 반환편은 해당 정류장 순서를 뒤집습니다.
정류장 이름은 routes.json에서 편집한 후 서버를 재시작하면 반영됩니다. 한 방향은 5개 정류장을 유지하세요.

원본 BusLive 접속판의 위치 전송 구조인 POST /api/share와 me.line을 바탕으로 모형의 위치 순번(me.step)을 추가했습니다.
이 앱과 펌웨어는 PC의 로컬 서버 주소로 연결됩니다. 원본 ZIP은 그대로 보관해도 됩니다.
